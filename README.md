❤️ Love You — Cinematic Animation Website

A romantic, cinematic web animation that transforms the words “Love You” into a beautiful visual experience using handwritten text effects, rose-gold typography, glowing lights, and expanding duplicate animations.

The website features a deep burgundy background, a faint crimson halo, floating particles, and a smooth animation that makes the phrase grow from a tiny size to its full size while duplicate text effects ripple outward.

✨ Features

✍️ Handwritten Text Animation — Reveals the “Love You” phrase with a writing effect.

💖 Expanding Text Effect — The phrase grows from very small to full size.

🌹 Duplicate Text Animation — Creates expanding, fading copies of the phrase for a cinematic effect.

🎨 Elegant Color Palette — Deep burgundy, rose gold, and crimson glow.

✨ Particle Effects — Floating particles and atmospheric bokeh.

🔆 Glow Controls — Toggle the glowing visual effects.

⏯️ Animation Controls — Pause, resume, and restart the animation.

🎵 Optional Sound Effects — Adds an extra interactive touch.

💕 Interactive Hearts — Click or tap to create floating heart effects.

📱 Responsive Design — Designed to work on desktop and mobile screens.

♿ Reduced Motion Support — Respects system preferences for reduced animation.

🛠️ Technologies Used

HTML5 — Website structure

CSS3 — Styling, glowing effects, and animations

JavaScript — Animation logic and interactive controls

SVG — Scalable text graphics and visual effects

Canvas API — Particle animation effects

🚀 How to Run Locally

Clone the repository:

git clone https://github.com/shubhamkguptatechi/Love-You.git
Open the project folder:

cd love-you-cinematic-animation

Open index.html in your browser.

Alternatively, open the folder in Visual Studio Code and launch the website using the Live Server extension.

No framework or package installation is required.

🎨 Design Concept

The website uses a romantic visual theme built around three main elements:

Deep Burgundy: Creates a rich, cinematic atmosphere.

Rose Gold: Gives the handwritten phrase an elegant appearance.

Crimson Halo: Adds a subtle glow behind the animation.

The central phrase remains upright while growing in size. Multiple fading duplicates expand outward to create a layered, dreamy visual effect.

💡 Inspiration

This project explores how simple web technologies can create expressive, emotional, and visually engaging experiences. It combines typography, motion, light, and interaction to turn a short romantic message into a cinematic animation.
